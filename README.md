# 🌿 Plant Disease Detection Prototype

##  Description

This project is a simple prototype that detects plant diseases using images. It helps identify whether a plant is healthy or affected by a disease.



##  Features

* Detects plant diseases from images
* Simple and easy to use
* Fast prediction



##  Technologies Used

* Python
* OpenCV
* Machine Learning / Deep Learning



##  How to Run

1. Install required libraries:
   pip install -r requirements.txt

2. Run the project:
   python main.py



##  Project Files

* main.py
* model file
* requirements.txt
* dataset (if included)



##  Output

The system takes an image of a plant and predicts whether it is healthy or diseased.
